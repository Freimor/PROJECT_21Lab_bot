# Публикации и мемы

## Будни / Важное

1. Автор сдаёт **исходник** (текст интервью и/или фото/GIF) без LLM.
2. Staff одобряет и запускает генерацию LLM → черновик в Telegram HTML (вложения остаются).
3. Staff правит, публикует или планирует.

Подпись автора (`— Имя | приставка ранг`) добавляется при публикации. `@ник` не пишется, чтобы не пинговать.

При **публикации** участнику-автору: **+20 благодати** и **+5 респекта** (один раз за пост). Staff не получает.

## Мемы

Модерация → коллекция шаблонов → постинг во флудилку. Формат: цитата + та же подпись автора.

Коллекции создаются и удаляются на странице **Публикации → Мемы** (блок «Коллекции мемов»). При удалении непустой коллекции нужно выбрать, куда перенести мемы. `default` удалить нельзя.

При **одобрении** мема участнику-автору: **+5 благодати** и **+1 респект** (один раз). Повторные автопосты из коллекции награду не дублируют.

## Реакции

На опубликованных Буднях и мемах реакции дополнительно крутят респект автора (см. топик «Реакции и респект»).

## LLM

Настройки модели (Ollama, температура, таймаут, директивы): **Настройки → Настройки LLM**.  
Шаблоны промптов и журнал: **Публикации → Посты с LLM**.

Ответ LLM — только Telegram HTML, без Markdown и без \`\`\`. Система дополнительно чистит «голые» `>` и markdown-фенсы.

| Тег | Эффект |
|-----|--------|
| `<b>…</b>` | **жирный** |
| `<i>…</i>` | *курсив* |
| `<u>…</u>` | подчёркнутый |
| `<s>…</s>` | зачёркнутый |
| `<code>…</code>` | моноширинный |
| `<pre>…</pre>` | блок кода |
| `<blockquote>…</blockquote>` | цитата |
| `<a href="https://…">текст</a>` | ссылка |
| `<tg-spoiler>…</tg-spoiler>` | спойлер |

Для черновиков обычно хватает: `<b> <i> <blockquote> <code> <pre>`.

Спецсимволы в тексте: `&lt;` `<`, `&gt;` `>`, `&amp;` `&`. Без Markdown (`**`, `_`, \`\`\`).
