# Удаление участников

Удаление — со страницы **Люди**. Нужно право `manage_staff`. Нельзя удалить себя.

## Что происходит

1. Снимается `staff_role`, `is_approved = false`, `is_active = false`.
2. Пишутся `removal_reason`, `removed_at`, `removed_by`.
3. Открытая заявка на вступление (если была) отклоняется.
4. Событие пишется в **журнал**.
5. Пользователю уходит ЛС с текстом по причине.
6. При наличии staff-чата — **кик** (ban + unban), без постоянного бана.

## Причины (`RemovalReason`)

| Код | Смысл | Сообщение пользователю |
|-----|--------|-------------------------|
| `rules` | нарушение правил | отдельная формулировка «по правилам» |
| `none` | прочее / без акцента на правилах | нейтральный текст удаления |

## Staff-чат

- **Одобрение staff** → одноразовый invite-link в ЛС. Бот **не** добавляет людей в группу сам.
- **Удаление** → kick из `STAFF_CHAT_ID`, если бот — админ чата с правом бана.

Если инвайт не пришёл: проверьте, что бот админ staff-чата и может создавать invite-ссылки.
