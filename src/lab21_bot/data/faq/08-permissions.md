# Матрица прав

Права задаются в `services/access.py` (`ROLE_PERMISSIONS`). Роль без права не увидит раздел в админке и получит отказ в боте.

## Права

| Право | Зачем |
|-------|--------|
| `manage_staff` | заявки, роли, удаление, люди |
| `manage_economy` | экономика, респект/благодать, refill % |
| `manage_store` | витрина: создание/правка товаров и услуг |
| `moderate_orders` | выдача/отмена заказов магазина |
| `moderate_content` | публикации, мемы, LLM-черновики |
| `create_staff_content` | staff-черновики / служебный контент |
| `manage_settings` | настройки бота, LLM, уведомлений, публикации |
| `manage_system` | перезагрузка/системные действия |

## Кто что может

| Роль | Права |
|------|--------|
| Тёмный лорд | всё, включая `manage_system` |
| Магистр | всё **кроме** `manage_system` |
| Техножрец | `manage_economy`, `create_staff_content` |
| Сервитор | `moderate_content`, `moderate_orders`, `create_staff_content` |

## Заметки

- В системе может быть **только один** Тёмный лорд.
- Назначение роли staff обнуляет благодать и респект цели.
- Лорд не может снять сам себя с роли лорда.
- Смена ролей — страница **Люди** (нужен `manage_staff`).
- Уведомления (чат сотрудников + браузер): **Настройки → Уведомления** (`manage_settings`).
