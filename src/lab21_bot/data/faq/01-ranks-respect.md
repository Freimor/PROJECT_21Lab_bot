# Ранги, респект и приставки

## Ранги участников

- **Послушник** — стартовый ранг, базовая благодать из `ranks.json`.
- **Адепт** — повышенный ранг (после апгрейда экономикой/заказами).

У сотрудников вместо ранга в подписи показывается **роль** (техножрец, сервитор и т.д.).

## Респект

Респект растёт за полезные действия сообщества:

- награды за **опубликованный пост** (+5) и **одобренный мем** (+1);
- **реакции** на посты/мемы;
- выполнение услуг и т.п.

Это «репутация у станка», не валюта магазина.

## Приставки по респекту

Приставка выбирается по текущему респекту (`data/prefixes.json`):

| Респект | Приставка |
|---------|-----------|
| 0–10 | обычный |
| 11–50 | узнаваемый |
| 51–150 | проверенный |
| 151–300 | ветеран |
| 301–600 | легенда |
| 601–1200 | миф |
| 1201–2500 | апостол |
| 2501+ | омниссия |

## Стандарт подписи автора

Единый формат для **мемов** и **постов** (Будни / Важное):

```
— Имя | приставка ранг
```

В Telegram HTML имя курсивом:

```
— <i>Ricky Shade</i> | обычный адепт
```

`@ник` в подпись не добавляется (в Telegram это пингует человека).
Подпись дописывается системой при публикации; LLM её не пишет.
