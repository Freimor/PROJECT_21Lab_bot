# О системе Lab21

Lab21 («Роболаба») — Telegram-бот и админка для сообщества инженеров-мейкеров: экономика **благодати** и **респекта**, магазин, услуги, навыки, публикации и LLM-редактура постов.

## Основные сущности

- **Участники** — ранги Послушник / Адепт, баланс благодати, респект, навыки.
- **Сотрудники** — роли (Тёмный лорд, Магистр, Техножрец, Сервитор) с правами в боте и админке.
- **Публикации** — Будни лабы, Важное, мемы; для Будней/Важного — двухэтапная модерация с LLM.
- **Магазин** — товары и услуги; услуги привязаны к навыкам.

## Где что править

| Тема | Где |
|------|-----|
| Ранги, роли | `data/ranks.json` |
| Приставки по респекту | `data/prefixes.json` |
| Навыки | `data/skills.json` |
| LLM-промпты (дефолт) | `data/llm_prompts.json` + админка «Посты с LLM → Шаблоны» |
| Модель LLM / уведомления | админка «Настройки» |
| Геймификация | админка «Геймификация»; `flavor_media.json`, фразы `presence` / `ritual` |
| Эта справка | `data/faq/*.md` |

Дальше — отдельные топики FAQ: ранги, экономика, навыки, публикации, роли, права, онбординг, реакции, флуд, каналы, планировщик, заказы/услуги, интервью, LLM, геймификация.
