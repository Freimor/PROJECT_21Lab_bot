# Роли сотрудников

| Роль | Суть |
|------|------|
| Тёмный лорд | Полный доступ, включая систему. В системе может быть только один. |
| Магистр | Почти всё, кроме обновления/перезагрузки. |
| Техножрец | Экономика и служебный контент. |
| Сервитор | Модерация контента и заказов. |

Права задаются в коде (`services/access.py`). Подробная матрица — топик **«Матрица прав»**. Смена ролей — страница **Люди** (нужны права manage_staff).
