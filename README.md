# Lab21 Bot

Telegram-бот инженерной лаборатории Lab21 («Роболаба»).

Помогает вести каналы сообщества, собирать материалы у участников и сотрудников,
вести внутреннюю экономику благодати и респекта, а также модерировать публикации
через бота и веб-админку.

## Что умеет

- оформление постов из заметок и коротких интервью с помощью локальной LLM;
- очередь публикаций, согласование и выпуск в каналы «Будни лабы» и «Важное»;
- мемы и тизеры для флудилки;
- онбординг участников и сотрудников с ролями (Лорд, Магистр, Техножрец, Смотрящий);
- ранги сообщества: Послушник и Адепт;
- экономика: начисления, списания, переводы, витрина и заказы;
- веб-админка для состава, витрины, публикаций и экономики;
- автообновление и перезагрузка бота из GitHub.

Тексты для LLM и служебные фразы вынесены в JSON в `src/lab21_bot/data/` —
их удобно править без правок кода.

## Стек

Python 3.12, aiogram 3, PostgreSQL, FastAPI-админка, локальная LLM (Ollama / vLLM),
Docker Compose.
